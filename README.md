# サンプルサイト — Café こもれび（架空のカフェ）

Web制作の受注用ポートフォリオとして制作した、架空のカフェの店舗サイトです。

## 概要
- ジャンル：飲食店（カフェ）公式サイト想定の1ページ構成
- 構成（全10セクション）：ヒーロー／お知らせ／当店について／店主のごあいさつ／メニュー（タブ切り替え）／ギャラリー／お客様の声／FAQ（アコーディオン）／アクセス／お問い合わせ・予約フォーム（デモ動作）
- 技術：HTML / CSS / JavaScript（フレームワークなし）、レスポンシブ対応（スマホ用ハンバーガーメニュー含む）
- 工夫：スクロール連動のフェードイン、固定ヘッダーの背景切り替え、メニュータブ、FAQアコーディオン、予約フォームの入力チェック＋完了表示、Google Fonts（Zen Old Mincho / Noto Sans JP）
- 画像：AI生成画像（店内・外観・ラテ・パンケーキ）を使用。実案件では店舗提供写真またはフリー素材に差し替え可能

## 注意
- 店舗名・住所・電話番号・価格はすべて架空のサンプルデータです（ポートフォリオ用の自主制作サンプルです）
- 予約フォームはデモ表示のみで、実際の送信は行いません
